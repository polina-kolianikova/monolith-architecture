# MONOLITH

A photographic architectural concept by BlackStack Studio. Three coherent generated images show the same limestone house, its living room and structural detail. The mobile page uses native flow and explicit image frames. Desktop retains an editorial grid and scroll-coupled photographic movement.

Serve this folder over HTTP. No build, API key or runtime CDN is needed. Fonts are local exact static weights for Safari interoperability. Photo assets are responsive WebP, with original generation prompts in the parent delivery workspace.

Exterior, Living and Detail switch the hero photograph. Light mood is a restrained photographic colour treatment, not a physically simulated sun study. Project notes reflect the selected view and can be downloaded. Native dialog controls, reduced motion, touch navigation and safe area spacing are supported.

The project is imagined. No commissioned building, property listing or freely navigable3D model is claimed. The former procedural building renderer is no longer used.
